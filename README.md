# Personal Expense Manager 💰

A simple-to-medium level **C++ console application** for managing personal income and expenses.

## Features

- Add income
- Set monthly budget
- Add expenses by category
- View all expenses
- View wallet summary
- Calculate savings percentage
- Find highest expense
- Search expenses by category
- Delete an expense
- Check budget usage and warnings
- Get personalized spending advice

## Technologies

- C++
- Object-Oriented Programming (OOP)
- Arrays
- Functions
- Loops and conditional statements
- Switch-case
- `string` and basic STL features

## How to Run

### Using g++

```bash
g++ main.cpp -o expense_manager
./expense_manager
```

### Windows

```bash
g++ main.cpp -o expense_manager.exe
expense_manager.exe
```

## How It Works

The application uses an `ExpenseManager` class to store income, expenses, categories, descriptions, and budget information. It provides a menu-driven interface where users can select different operations.
